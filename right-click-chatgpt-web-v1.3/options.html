Gemini → Telegram / Zalo OA

Bôi đen câu hỏi, giữ Alt rồi nhấn chuột phải để Gemini trả lời và chuyển kết quả qua kênh đã chọn. Chuột phải bình thường vẫn gửi sang ChatGPT Web như trước.

Gemini API

Model mặc định là gemini-3.8-flash. Bạn có thể thay đổi nếu tài khoản/API của bạn dùng model khác.

Kênh nhận câu trả lời
Telegram

Tạo bot bằng BotFather, rồi lấy Chat ID của cuộc trò chuyện hoặc nhóm mà bot được phép gửi tin.

Zalo Official Account (OA)

Cần OA, Access Token hợp lệ và user_id của người nhận đã quan tâm OA. API này không phải API nhắn tin trực tiếp cho tài khoản Zalo cá nhân bất kỳ.

Thông tin cấu hình được lưu trong chrome.storage.local trên hồ sơ Chrome này. Không dán API key/token vào GitHub hoặc chia sẻ thư mục cấu hình.
