Gemini → Telegram

Chọn chế độ Gemini → Telegram trong popup; bôi đen văn bản rồi chuột phải để chạy. Nếu model lỗi, trang này sẽ lưu lại model và chi tiết lỗi để xem sau.

Gemini API

Tải danh sách để xem model được API liệt kê. Sau đó bấm “Kiểm tra model đang chọn” để gửi thử một prompt nhỏ và xác minh model thực sự chạy được với API key hiện tại.

Lần Gemini gần nhất: Chưa có dữ liệu.

Telegram Bot

Tạo bot bằng BotFather. Mở cuộc trò chuyện với bot và gửi /start trước khi thử gửi tin nhắn.

Thông tin cấu hình được lưu trong chrome.storage.local trên hồ sơ Chrome này. Không dán API key/token vào GitHub hoặc chia sẻ thông tin cấu hình.
